# Валютный калькулятор

Локальная одностраничная версия калькулятора курсов ЦБ РФ.

## Запуск

Откройте `index.html` в браузере. Для загрузки курсов требуется интернет.

Если браузер блокирует сетевой запрос при открытии файла напрямую, запустите локальный сервер из этой папки, например:

```powershell
python -m http.server 8080
```

После этого откройте `http://localhost:8080`.

## Источник данных

Архив cbr-xml-daily.ru: `https://www.cbr-xml-daily.ru/archive/ГГГГ/ММ/ДД/daily_json.js`.
